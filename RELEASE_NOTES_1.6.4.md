# Parity 1.6.4

Parity 1.6.4 expands Crawl analysis and brings the growing toolset into a more compact, task-based workspace.

## Clearer navigation and findings

- Related controls share sections and containers, with focused settings and investigation panels.
- Overview and Issues summarize finding types by severity, affected URLs and independent High/Medium/Low priority. Unknown rules remain unrated.
- Compact tables, SVG icons and clearer grouping improve use of the available screen space.

## More crawl evidence

- Expanded source, response, indexing, discovery, security, content and link investigation.
- Selected-text similarity, named searches, source extraction previews, social metadata, local English spelling/grammar and bounded PDF analysis.
- Saved browser evidence covers rendered differences, requests, storage, frames, shadow DOM, mobile presentation and image review.
- Structured-data guidance, sitemap metadata and generation, opt-in automated accessibility checks, and selected local or explicitly requested remote performance observations.
- AMP declarations, optional target discovery, offline validation and saved relationship review; meta-keyword inventory and disclosed transfer-impact scenarios.

## Saved workflows and integrations

- Saved segments, selected-URL refresh, richer comparisons, report presets, XLSX exports and portable crawl packages.
- Configurable queue and capacity controls, storage review and opt-in local recurring schedules.
- Search Console and GA4 correlation, explicit Google URL Inspection and offline URL investigation.
- Backlink and authority exports can be imported without a paid SEO subscription. No paid backlink API is required.
- Headless CLI and project-scoped MCP tools reuse the Crawl engine. Optional configured agents support cited AI suggestions and semantic analysis.

## Graph exploration

- Directory tree, force and radial views, saved body/anchor word frequencies and semantic peer groups.
- Optional 3D crawl/directory views use **left-drag to pan**, **right-drag to rotate** and **scroll to zoom**, replacing the sliders.
- Node selection, double-click branch focus, keyboard controls, camera reset and scoped offline exports remain available.

Coverage, retention and resource limits remain visible. Missing or blocked evidence is not counted as a successful assessment. Google tools require authorized access to the selected property; optional remote performance and AI/embedding requests require their corresponding configuration and may incur provider charges. Local schedules require Parity to be running. Additional browser engines remain prototype work and are not offered as production capture modes.

The Windows installer uses the existing public update feed and preserves application data. It retains the packaging cleanup from the 1.6.3 rebuild and is scanned locally with Microsoft Defender before publication. The installer remains unsigned; a local scan does not establish a verdict on every device.
